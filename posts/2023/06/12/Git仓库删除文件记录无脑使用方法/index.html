Git仓库删除文件记录无脑使用方法

发表于 2023-06-12 更新于 2025-06-25 分类于 Git 本文字数： 173 阅读时长 ≈ 1 分钟
将不需要的文件永久从Git提交中删除以裁剪仓库，但是Commit ID会改变。

方法一：filter-branch

执行

git filter-branch --force --index-filter "git rm --cached --ignore-unmatch <path-to-your-remove-file>" --prune-empty --tag-name-filter cat -- --all

即可删除[1]。

注：

  1. <path-to-your-remove-file>替换为要删除的文件，可以使用通配符；
  2. Linux里可以使用单引号，但是Windows里只能用双引号[2]；

将修改后的提交推送到远端：

git push origin master --force --all
git push origin master --force --tags

清理、回收空间：

git gc --aggressive --prune=now

参考

  1. Git如何永久删除文件(包括历史记录) - shines77 - 博客园；
  2. Removing files from git history - bad revision error - Stack Overflow；
