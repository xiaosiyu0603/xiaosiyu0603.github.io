区别项

粗体为推荐选择

架构

  • i686：32位x86
  • x86_64：64位x86_64

线程模型

  • win32：基于 Windows 原生线程（Windows API）
  • posix：基于 POSIX 线程标准
  • mcf：Mingw-w64 C Library Fork， mingw-w64 项目的一个特定优化版本

运行时

  • msvcrt：Microsoft Visual C Runtime Library （VC6）
  • ucrt：Universal C Runtime Library （Win10起）
